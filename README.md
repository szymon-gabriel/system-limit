# SYSTEM_LIMIT_/ // Habit Tracker & Protocol Engine

A cyberpunk-inspired, production-ready Progressive Web Application (PWA) engineered for high-density daily habit management, visual streak tracking, and personal protocol enforcement.

---

## 🚀 Live Production Environment

The application is deployed as a standalone Web App (PWA) with complete touch optimization, offline capability, and native launcher integration.

**Access the system interface here:** https://szymon-gabriel.github.io/system-limit

---

## 🧠 Engineered Features & Core Architecture

* **Progressive Web App (PWA) Native Shell:** Configured via `manifest.json` and customized SVG icons to deliver a borderless, full-screen mobile app experience directly on Android and iOS.
* **Dark Cyber / Glassmorphism UI:** Built with custom high-contrast color palettes (`#050206` base, `#ff1a43` neon accents) and blur mechanics for clear visual hierarchy.
* **Persistent Local State Management:** Native client-side storage architecture ensuring zero data latency, instant habit toggles, and multi-session persistence without cloud dependencies.
* **Custom SVG Brand Integration:** Handcrafted geometric monogram visual assets with dynamic CSS filters and gradient depth layers.

---

## 🏗️ Repository Directory Layout

* `index.html` - Primary interface structural layer, CSS design tokens, and local state application logic.
* `manifest.json` - PWA configuration layer defining viewport display parameters, app metadata, and launcher icon hooks.
* `icon.svg` - Scalable vector branding asset with glassmorphic depth effects and glow filters.
* `README.md` - System architecture documentation and deployment overview.

---

## ⚙️ Core Technology Stack

* **HTML5 / CSS3:** Semantic markup, custom CSS variables, glassmorphic filters, and fluid layouts.
* **JavaScript (ES6+):** Event-driven state updates, local storage sync algorithms, and dynamic DOM rendering.
* **Web Manifest API:** Native PWA setup for standalone execution and mobile home screen installation.
